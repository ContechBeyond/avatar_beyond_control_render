BEYOND - ACTUALIZAR EL PANEL EXISTENTE EN RENDER

Este paquete agrega los recorridos del showroom y sus ocho temas.
Usa el mismo servicio, URL, CONTROL_ACCESS_KEY y DEVICE_TOKEN que ya tienes.

1. Extrae el ZIP.
2. En GitHub abre el MISMO repositorio que esta conectado a tu servicio de Render.
3. En Add file > Upload files sube el contenido extraido y guarda los cambios.
   server.js, commands.js y render.yaml deben quedar en la raiz del repositorio,
   junto con package.json, package-lock.json y la carpeta public.
4. Espera a que Render publique el ultimo cambio. Si no lo hace automaticamente,
   abre el servicio y usa Manual Deploy > Deploy latest commit.
5. Espera a que aparezca Live y recarga la pagina en el celular.

Recibir visita utiliza Ejecutivo por defecto: temas 1, 2, 3 y cierre.
Puedes seleccionar Breve, Ejecutivo o Completo.
Continuar salta al siguiente tema del recorrido.
Elegir tema reproduce un bloque independiente.
Pasar al SOC interrumpe cualquier bloque y reproduce el cierre.
La casilla Esperar mi indicacion entre temas permite una visita guiada.

Estos controles requieren el nuevo Beyond Avatar.exe del showroom.
No crees otro servicio ni reemplaces las claves existentes para esta actualizacion.
Los archivos de configuracion privada de cada PC no van dentro de este paquete.

Guia oficial de publicacion:
https://render.com/docs/deploys#manual-deploys
